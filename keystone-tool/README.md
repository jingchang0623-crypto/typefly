# 投影梯形预矫正工具 (Keystone Pre-Warp)

一个纯前端、单文件的在线工具，用于**无 T 型梯形矫正**的斜角投影设备。
它把普通矩形图片反向预畸变成「带透视角的梯形图」，投到纸面后即还原为正矩形。

> 适用场景：绘画/临摹投影仪，光机镜头斜射桌面，目标投影区为固定矩形（如 22.98×12.92 cm）。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器、无需安装）。也可部署到任意静态托管。

1. **上传图片**：点击或拖拽，支持批量、多选（PNG/JPG/WEBP）。
2. **设置透视参数**
   - **透视方向**：被收窄的那条边（= 投影时被放大的「远边」）。桌面斜投通常选「上窄」。
   - **投影倾角 θ**：光轴与纸面法线的夹角。
   - **收缩比例 r**：窄边/宽边宽度比，可手动微调；也可在「高级」里由 θ、φ 自动计算。
3. **输出设置**：宽高比（默认 16:9）、分辨率、内容边距、背景（透明/黑/白/自定义）。
4. **校准**：点「生成校准网格图」，投到桌面，对照目标矩形微调 r 与方向，直到边缘对齐。
5. **导出**：`导出当前 PNG` / `批量导出 ZIP` / `逐个下载`。

## 原理

斜角投影是一个平面射影变换（homography），会把矩形投成梯形，远端被放大。
本工具对图片施加其**逆变换**——把单位方块映射到「窄边在远端」的等腰梯形，
用 2D 画布网格细分 + 逐三角仿射贴图实现透视，投影后即抵消畸变。

收缩比例的几何来源（沿俯仰方向、对称倾斜）：

```
r = 近边/远边的投影放大比 = sin(90−θ−φ) / sin(90−θ+φ)
```

其中 θ 为光轴与法线夹角，φ 为镜头垂直半视场角。
对示例设备 θ=35°、中心斜距 D=19 cm、目标 22.98×12.92 cm（16:9），
由投影深度公式反解得 φ≈15°，故 r≈68%（默认值）。实际装机后以校准图实拍微调为准。
